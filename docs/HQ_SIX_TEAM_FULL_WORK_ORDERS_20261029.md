# 한글쉽지 6개 개발팀 전수 작업지시서 — 160개 계약
기준: 2026-10-29. 대표 지시: 160개 전체를 각 팀에 한꺼번에 명시적으로 배분하고, 검증된 범위에서 자율 실행·다음 과제 승계를 수행한다.

## 공통 실행 명령
1. 각 팀은 아래에 배정된 **전체 번호**와 원문 `automation/hq_backlog_160.md` 및 `docs/HQ_160_DEVELOPMENT_CONTRACTS_20261029.md`를 매 실행 읽는다. 작업이 없다는 이유로 WAIT 하기 전에 자기 팀의 미완료 전체 번호를 검색한다.
2. 번호별 기존 구현, 실제 소스/테스트 경로, 의존성, 실패 원인, 승인 조건을 확인한다. 불명확한 과제는 무작정 수정하지 말고 경로·테스트를 탐색하여 CANDIDATE 계약을 상세화하고 독립 QA를 요청한다.
3. 독립 검증을 거쳐 READY가 된 과제만 AI 개발 runner에 넣는다. 기존 검증 완료 작업을 중복 개발하지 않는다. READY=0이면 계약 상세화·독립 테스트·회귀 검증·막힌 원인 해소를 수행한다.
4. 팀별 변경은 격리 브랜치에서 진행한다. 동일 파일 충돌을 막고, 실패→재현→수정→독립 재검증을 거친다. 코드 검증/실사용 검증/대표 승인을 별도 기록한다.
5. 매 실행은 실제 변경 파일, 커밋 SHA, CI 링크, AI 호출 수, 신규 고유 과제, 차단 사유, **다음 과제 번호**를 보고한다. 6팀 신규 봇 커밋과 총괄본부 직접 수정은 분리한다.
6. main·공개 배포·운영 DB·실결제·실제 지원사업 제출·실제 투자자 접촉은 별도 대표 승인 없이는 실행하지 않는다.
