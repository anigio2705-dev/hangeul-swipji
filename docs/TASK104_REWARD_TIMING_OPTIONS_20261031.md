## 2. 가상 이벤트 계약과 검증

- `phase3/team14_reward_timing_sim.py::simulate_reward_timing`은 외부 DB/예약/결제 API를 호출하지 않는 **순수 계산 함수**. `payment_at`, `completion_at`, `refund_at`, `as_of`는 정수 Unix 초, 선택된 가상 후보는 `on_payment`, `on_completion`, `after_refund_window`.
- 결제 없음/미래 결제는 `WAIT_PAYMENT`, 미완료 수업은 B/C에서 `WAIT_LESSON`, 대기 기간 전에는 `WAIT_TRIGGER` 또는 `PROVISIONAL_REFUND_RISK`, 환불 발생은 `VOID_REFUND` (이전 발생 후보도 소급 무효).
- 가상 C 경계는 `max(결제시점, 완료시점)+가상 대기초`. 바로 전 초와 정확한 경계 초, 결제·완료 역순, 조기/늦은 환불, 미래 환불, 0일 경계, 누락/음수/bool 입력을 테스트.
- 출력 `safe_to_confirm_simulated`는 **비교용 조건식일 뿐** 실제 송금·지급 허가가 아니다. 모든 반환에서 `real_money=False`, `policy_approved=False`, `payment_enabled=False`. 실제 결제·지급·DB 쓰기·운영 배포 금지.
