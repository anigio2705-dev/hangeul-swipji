# 한글쉽지 6팀 통합 브레인스토밍 결정서 (2026-10-29)

상태: 조직 설계와 기존 소스 대조. 팀 AI 실제 회신 또는 실시간 회의를 수행했다고 주장하지 않는다. 자동화 중지 상태 유지.

## 공통 목표
하나의 홈페이지에서 외국인 학습자가 무료 교육을 받고, 필요하면 한국인 회화 파트너 또는 전문 강사를 선택해 화상수업을 받고, 수업/결제/정산/소개 보상이 연결되는 플랫폼. 기존 자산 보존, 새 기능은 테스트99에서 검증 후 운영 반영.

## 팀별 단일 책임
11 공통 기반: 회원/역할/보안/DB/백업/API/배포, 작업 큐와 병렬 AI 개발 엔진, 팀 간 인터페이스 계약. 테스트99 임시 데이터 보존 검증 전 재배포 금지.
12 교육 개발: **하나의 팀, 하나의 교육과정 기준**. 무료 350단원·퀴즈·읽기·음원 내용 전수 감사 및 재제작, 학습자용 교재·숙제·복습·평가, 강사용 지도서·수업 시나리오·오류 교정, 회화 파트너용 진행 자료. 교육 원본의 단일 소스와 버전 관리. 세종학당 등 비교.
13 플랫폼: **홈페이지 디자인/UX 전담 파트는 13팀 내부에 둔다**. 첫 화면/다국어/모바일/접근성, 무료 학습 UI, 학생·강사 등록, 즉시 매칭/예약 매칭, 양측 화상 접속, 수업 화면과 교재/과제 통합.
14 사업 시스템: 단과/월 수업, 예약/이행, 결제 시뮬레이션, 수수료/보수/환불/정산, 소개/다단계 보상 시뮬레이션, 관리 화면. 정책/법률 검토 전 실제 돈 지급 금지.
15 품질·운영: 모든 팀 결과의 독립 사용자 여정 검증. 학습/발음/교재/화상/예약/거래/모바일/다국어/데이터 복구. CODE 검증과 실제 테스트99 검증 구분. 실패 시 재배정.
16 글로벌 성장: 시장/경쟁/차별화, 8개 우선 언어 UX, 강사·학습자 확보, 광고/SNS/제휴/외주, 무료→유료 전환/유지율/획득비용 검증. 13·14팀에 전환 개선 요청.

## 공동 인터페이스와 책임
교육자료/수업 ID·수준·학습목표·버전: 12팀 소유, 13팀 화면 사용, 15팀 내용 검증.
사용자/역할/인증/데이터 계약: 11팀 소유, 13·14팀 사용, 15팀 보안 검증.
매칭/예약/화상 세션 상태: 13팀 소유, 14팀 수업 이행·정산 연계, 15팀 양측 테스트.
가격/결제/보상 원장: 14팀 소유, 13팀 화면 사용, 15팀 계산/환불 검증.
홈페이지 디자인 시스템: 13팀 내부 디자인 파트 소유, 12·14·16팀 요구 수렴, 15팀 접근성 검증.
시장 지표/유료 전환 이벤트: 16팀 정의, 11팀 계측 기반, 13·14팀 이벤트 발생, 15팀 데이터 정확성 검증.

## 자동화 3층
한글쉽지 무인 개발: 11팀이 실제 개발 작업 큐, 격리 브랜치, 팀별 실행, 테스트/재시도, 결과 기록을 구현. 보고만 하는 자동화는 불합격.
한글쉽지 AI 개발 결과 확인: 15팀이 팀별 코드·콘텐츠·UI·통합 테스트 증거를 수집하고 PASS/RETRY/BLOCKED 판정.
한글쉽지 총괄본부: 전체 목표·우선순위·팀 간 충돌/의존성·160항목 관리, 독립 검증과 실제 제품 성과 확인, 대표 보고·승인 요청.

## 통합 실증 5개
A 학생이 가입 없이 무료 학습 진입→자모 실제 발음→단원 학습→문항 풀이→진도 저장(저장 필요 시 로그인).
B 학생이 강사 검색→예약→양측 수락→화상 입장→학생·강사 교재 열람→숙제·평가.
C 학생이 즉시 회화 파트너 찾기→자동 매칭→양측 화상 연결→종료.
D 수업 예약→모의 결제→이행→모의 수수료/보수/환불/소개 보상 계산.
E PC·모바일·우선 8개 언어에서 전체 화면과 기능이 연결되고 데이터가 보존됨.

## 판단
현재 소스에 학습 페이지·한글 글자판·전문 96수업 데이터·테스트99 서버 등이 존재하나, 실제 홈페이지/테스트99에서 A~E 전 과정이 통과했다는 증거는 없다. 따라서 하나의 제품으로 **구현 가능**, 현재 **완성/정상 자동화는 미입증**. 다음 실행은 팀별 작업 수집과 A~E 실패 항목의 실제 수정부터 진행. 자동화 중지 해제나 배포는 별도 지시가 필요하다.
