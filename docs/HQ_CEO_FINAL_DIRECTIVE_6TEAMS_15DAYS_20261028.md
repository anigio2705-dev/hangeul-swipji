## D. 상태·자동 배포 규칙
각 팀은 GitHub Issue를 수신함으로써 지시를 **열람 가능**하다. 이는 다른 ChatGPT 창을 자동 시작시키지 않는다. 실행 자동화는 실제 GitHub Actions/에이전트 연결과 권한이 확인될 때만 주장한다.
각 작업의 상태: NOT_STARTED / IN_PROGRESS / CODE_DONE / CI_PASS / STAGING_VERIFIED / EXTERNAL_APPROVAL_REQUIRED / BLOCKED / DONE.
완료 증거 템플릿: 작업번호, 담당팀, 변경 경로, 브랜치, SHA, 테스트 명령과 결과, 99 실제 SHA 및 브라우저 증거, 실패/잔여위험, 사람 조치 필요 여부, 다음 작업.
사람 요청 템플릿: 필요한 주체/행동/권한/근거/마감/미조치 영향/AI 대안.
팀은 이 문서를 우선 기준으로 하고 매일 GitHub Issue에 진척·증거를 기록한다. 지시를 임의로 기각하거나 일정만 늘리지 않는다.
