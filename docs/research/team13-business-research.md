### 1-1. 독립적인 차별화 아이디어 (8개)
1. **대화권 1회 완성 루프**: 무료 단어/문장 5분→'이 표현 말해보기'→검증 파트너 15분 유료 회화→3개 오류 피드백→다음 학습. 구매 전 가치를 보여주고 복습으로 재구매를 만든다. KPI: 학습→예약 전환, 회화 후 7일 재예약.
2. **'한국 생활 미션' 패키지**: 카페 주문·면접·병원 방문·대학교·여행 5개 실제 상황. 같은 회화 파트너와 4회 묶음 수업. 무료 검색 유입→상황형 결제→패키지 재구매.
3. **즉시 매칭 + 예약 병행**: 저가 일반 파트너 즉시 15분, 고가 전문 강사 예약 30~50분. 대기 파트너 없으면 '다음 가능한 시간'으로 전환. 공급 가동률·예약 성공 개선.
4. **지역별 '한국어 대화 클럽'**: 베트남어·영어 현지 커뮤니티/크리에이터가 링크로 온라인 그룹을 유치; 실거래 첫 수업에만 제휴 보상. 광고 CAC 대체·품질관리 가능.
5. **강사 마이크로 프로필 + 체험 성과**: 가격뿐 아니라 발음 정확도, 수업 시간 준수, 재구매율, 취소율 표시(표본 부족·개인정보 보호). 검색 신뢰→예약 전환.
6. **문장-발음-사람 연결**: 사람 목소리 음원/명시적 TTS 및 교정 1문장 후 한국인 파트너와 비교. 'TTS를 사람 목소리로 속이지 않음'. 발음 미션 고객 유입→유료 교정.
7. **회화 수업 안전 보장**: 수업 오류·노쇼에 대한 명확한 재예약/환불 창구, 가짜 접속만으로 자동 완료·정산 금지. 불안 해소→첫 구매/재구매.
8. **강사 자신이 홍보 채널**: 강사별 QR/소개 URL로 무료 미션·수업 전환율 대시보드; 실적 검증 후 법률상 허용되는 직접 거래 보상만 지급. 낮은 마케팅비, 매칭 공급을 동시에 개선.

위 아이디어는 **검증된 성과가 아니라 실험할 사업 가설**이다.

## 2. 무료 교육 설계와 유료 연결
- 첫 방문: 언어 선택(우선 영어+베트남어; 번역 감수 후 확대)→목적(여행·취업·K-콘텐츠·TOPIK)→3분 진단.
- 무료 핵심: 하루 5~8분 **발음→표현 3개→상황 듣기→따라 말하기→퀴즈**. 각 여정 끝에 '한국인과 사용해 보기' CTA. 350 원본은 삭제 금지, 출시에 필요한 30~50개만 교사 감수·모바일 품질 확보.
- 무료에서 절대 막지 않을 것: 기초 한글·문법·진도·틀린 문제 복습. 유료 강요 팝업·진도 인질화 금지.
- 가격 페이지: 일반 파트너 15~25분 1회 및 4회 패키지, 전문 강사 30~50분 별도 요율. **가상의 가격 실험**: 일반 파트너 25분 25,000원, 전문 강사 50분 45,000원. 1차 가격 조사로 조정.
- 수업 전/후 품질: 예약시간 확정→진입 권한→양측 실제 입장/진행 증거→학습 피드백→7일 재예약 알림(수신 동의 기반).
- 지표: 무료 첫 학습 완료율, D1/D7 재방문, CTA 클릭, 예약 시작→결제 성공, 예약→실수업 진행, 7/30일 재구매, 환불, 교사 시간당 공급/가동률.

## 3. 법률 위험을 통제한 네트워크 확장 및 수익 배분
**선택안: 1단계 제휴 추천 보상, 2~N단계 하위모집/하위거래 연쇄 수당은 제외.** '암웨이 원리'의 복제는 등록·판매원 단계·후원수당·해외 유사 규정 위반 가능성이 있으므로 초기에 채택하지 않는다. 한국 「방문판매 등에 관한 법률」의 다단계 후원수당 규정과 사행적 확장 금지 조항을 실제 구조별 법률 자문으로 확인해야 한다. 참고 https://law.go.kr/LSW/lsInfoP.do?lsiSeq=290239 ; https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0020&lsiSeq=268293&urlMode=lsScJoRltInfoR .
- 소개 보상 발생 조건: 가입/클릭/유입 수가 아니라 **실제 결제·수업 완료·환불 보류기간 종료**. 환불·차지백 시 보상 취소/회수. 동일인·가짜수업·셀프추천·다계정·봇 방지.
- 실험 가정: 유료 1회 수업 25,000원, 파트너 80%(20,000원), 플랫폼 20%(5,000원). 이때 결제수수료 750원(3%), CS/분쟁 500원, 제휴 추천 평균 250원(유료 거래의 1%를 전체 거래에 평균 반영)으로 **실제 가정상 플랫폼 기여이익 3,500원/회**. 세금, 부가세 적용, 고정비·추가 보안·환차손·지급비·환불 손실은 별도. 이 가정이 사업 결과를 보장하지 않는다.
- 인센티브 원칙: 소속 파트너/교사에게 신규 회원 모집 의무·가입비·강제 구매 없음. 제휴 클릭·직접 기여 단일 단계만. 전문 강사의 신뢰·품질 지표가 초대 보상보다 우선.
- 해외의 경우 각국 플랫폼·프리랜서 노동·세금·송금·전자상거래·광고 표시·개인정보 법률을 사업 출시 전에 확인.
- 정산 원칙: 서버 소유 예약ID/수업 완료 증거/가격·실거래 확인→환불 기간/분쟁 상태→원장 확정→소개 보상. 서버 이벤트와 별도 DB는 정확히 한 번의 회계 처리를 **이벤트 ID 멱등성**으로 구현; 양쪽 DB 원자 트랜잭션을 가정하지 않는다.

## 5. 단위 경제성·CAC·전환율·재구매의 손익분기 **가정**
- 기준 *실험 가정*: 첫 수업 거래 25,000원, 실거래 수수료 20%, 파트너 지급 80%, 결제료 3%, 수업당 CS·분쟁 평균 500원, 평균 제휴 비용 250원. **기여이익/회 = 25,000×0.20 − 750 − 500 − 250 = 3,500원**(부가세·법정 세금·추가 환불 손실·고정비 제외).
- 유료 고객 한 명이 90일 동안 평균 4회 실제 완료한다면 **90일 기여 LTV=14,000원**. 고정비 흑자까지 의미하지 않음. 1회면 3,500원, 8회면 28,000원.
- 광고로 **유료 고객** 획득 CAC가 14,000원 이상이면 이 4회 가정에서는 기여금이 0 이하. 보수적 손익분기 **CAC≤10,000원**을 초안으로 잡아 환불/오차/고정비 여유를 확보. 강사 직접 유입은 별도 표시.
- 무료 등록자 대비 유료 전환율 `p=5%` 가정이면 100명 중 5명 결제, 평균 4회 완료 시 기여금 총 70,000원 → **무료 등록/획득 1인당 허용 광고비 700원**. 100명당 광고비 70,000원 이하가 변동원가 기준 손익분기. p=2%이면 280원, p=10%이면 1,400원. 무료 학습을 실제로 끝내지 않은 방문자를 분모에 섞지 않는다.
- 30일 내 재구매율 40%, 유료 코호트 90일 평균 4회, 환불 5% 이하, 예약→실제 수업 완료 90% 이상, 매칭 2분 안에 성공 70% 이상은 **출시 전 목표 가정**이지 현재 실적이 아니다. 운영 4주마다 재측정.
- 총 매출·기업 이익 구분: `총거래액 GMV = 총 완료 매출`, `플랫폼 매출(회계정책/세법 검토 전 가정)=GMV×수수료율`, `기여이익=플랫폼 매출−PG−보상−CS−환불충당 등`. 강사 보수는 인건비가 아니라 중개 구조의 정산 의무로 명확히 구분.
- 손익 실패 시: 광고 중단→파트너 가격/수업 시간과 수수료 비교→4회 패키지 재구매 개선→최대 추천 보상 낮춤→일정 지연. 광고비 확대 조건은 2개 연속 코호트의 90일 LTV/CAC ≥1.5와 환불 및 품질 지표 충족. 표본 작은 4주 실험에서는 의사결정 유예.

| 14 서버 배포·영속 데이터·보안·운영 자동화 | **현재 환경만으로 완수 불가 / 권한 확보 시 가능** | 배포 스크립트·CI·백업 코드는 가능 | Render 유료 영구저장 또는 관리형 DB, 운영비 수만원~수십만원+/월; 4~8주 | Render 서비스 관리자 권한, DB백업 복원 리허설·보안 책임 | 99 Render 현재 SHA 미확인, 임시 SQLite 유실 위험, 실제 운영 검증 불가 |

**AI 도구 역할 구분**: ChatGPT=설계·분석·코드 제안/연결 권한 내 GitHub 변경; Codex=실제 저장소 작업·테스트·PR 검토(실행 환경 필요); Work=웹·문서·앱에 걸친 다단계 실행(사용자가 해당 모드/권한을 제공한 경우). 셋 다 PG 계약 승인, 법률 판단의 책임, 원어민 청취 검수, 실제 두 물리 기기의 송수신이나 Render 관리자 권한을 마술처럼 만들지 못한다.
- 현 연결로 실제 **불가능한 일**: Render 관리 인증 없이 기존 99의 최신 SHA를 수동 배포했다는 사실 입증; 카메라/마이크가 있는 다른 두 사용자 기기에서 실제 대화가 됐다고 입증; PG와 계약/실결제 없이 실제 정산금 송금.
- **만들 수 있는 일**: 데이터 구조/상태머신/중복 방지/시뮬레이션/자동 테스트/이벤트 추적·초기 콘텐츠 제작. 자동 검사는 실사업 검수의 한 단계일 뿐.

## 8. 실제 코드 재사용·버그 해결 우선순위
**버리지 않을 것**
- `phase3/instant_matching.py` 큐·ready·매칭 고유 인덱스·인증/예약/Outbox, `phase3/instant-speaking.html` 기본 화면, 11번 예약/세션·12번 무료학습 데이터, 14번 `team14_instant_verified_bridge.py`의 실제 DB 조회·모의 정산 수신.
- `phase3/instant-browser-test.cjs`의 *로컬 모의화상* 테스트를 회귀 게이트로 유지. 실제 통화 성공으로 오인하지 않음.
**P0 수정**
1. Render 배포 SHA·SQLite 백업/영구 DB 및 실제 관리자 계정/게이트 접근 확보 **후** 통합 브랜치 교차검증. 원장에 비밀값 공유 요청 금지.
2. `end(db,m)`가 매칭만 종료하고 'in_class' 즉시 예약이 남을 수 있음: 정상 완료·연결종료·취소·노쇼 정책을 분리하고 예약 DB/정산 이벤트와 일관화.
3. 양측 `session-observe`는 곧바로 완료 가능: 실 화상 공급자와 연결된 최소 시간·출석 및 수업 증거(합의된 정책), 조기 완료 방어를 서버에 추가.
4. `phase3/instant-speaking.html` '예약 없이 대화' 문구와 자동예약 생성 불일치; 본인 수업/예약/완료 UI 연결.
5. Jitsi 서버의 URL 공유·방 진행자 인증/대기실 등 제공자 권한 검증, 실제 2기기 영상·음성 테스트.
6. 실거래 이전 PG 샌드박스→실금액 원장 매핑·소개 보상 환불 회수·별도 SQLite eventId 중복정산 방지→15번 E2E.
7. 무료 한글 글자판의 실제 녹음 파일/404/소리 실패 12팀과 시정; 재생했다고 코드만으로 판단 금지.
**P1/P2**
- 모바일/다국어 언어 전환, UX/로그·관리자 큐·이벤트 추적, 알림/재예약, 관측성/부하, 고급 레벨/전국가 확장 순.
**거절할 우회**
- 한쪽 완료 버튼만으로 정산 확정, mock iframe을 실통화로 보고, 99 DB 임시 저장으로 실거래, 유료 회원·강사 모집 전 PG/환불 보증 없는 결제, 계층적 모집 수당부터 구현하는 방식.

## 10. 11·12·14·15팀에 제기하는 독립 반론·질문

- **15번**: 기존 Render SHA·관리자 실화면·2실기기 영상·음성 근거가 없다면 통합 CI 성공만으로 출시 완료를 선언하지 않는가? 현재 110개 팀13 감사 항목을 원본 ID로 집계하고 있는가?
