# Shared lessons: evidence before promotion

1. Do not promote a single passing team regression to an integration or deployment success. Record CODE, TESTED, INDEPENDENT, INTEGRATED, DEPLOYED separately.
2. On CI failure, distinguish dependency/runner faults from product faults; pin compatible environments, add bounded retries and log diagnostics.
3. Do not modify source-protected original learning HTML to inject previews. Keep staging-only UI outside immutable files and audit byte-for-byte.
4. Scope `notranslate` to Hangul glyphs and audio controls, not whole lesson descriptions. Test translated content, not just the selector label.
5. Record failed hypotheses and exact SHA/CI URLs so the next team can skip disproven approaches.
6. A cross-team reuse claim requires its own code change, passing test and source-case link; do not infer success from the original team's result.
