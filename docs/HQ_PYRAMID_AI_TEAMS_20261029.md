# 한글쉽지 6팀 피라미드형 AI 조직·업무 분배안
2026-10-29 / 설계안. 실제 다중 AI 인스턴스가 생성·작동한 증거는 아직 없다. 중지된 자동화 재가동 금지.

대표 → AI 총괄본부 → 6개 팀장 AI → 각 팀 내부 파트장/작업자 AI → 독립 검수(15팀).

11 공통 기반팀: 자동화 오케스트레이션 파트(작업 큐·실행·재시도), 계정/권한 파트, 데이터/백업 파트, API·통합 파트, 배포·인프라 파트, 보안 파트. 팀장 산출물은 병렬 실행 기록과 통합 가능한 공통 기반.

12 교육 개발팀(교육 기준 단일 책임): 교육과정·수준 설계 파트, 무료 350단원 교재 파트, 발음·음성·듣기 파트, 읽기·쓰기·문법 파트, 학생용 교재·숙제·평가 파트, 전문 96수업·강사용 지도서 파트, 회화 파트너 수업 가이드 파트, 교육 콘텐츠 의미 검토 파트. 모든 파트가 동일한 수준표·교육 목표·용어집·단원 ID를 공유하고 12팀장만 교육 원본 변경 승인 제안. 강사용/학생용 자료는 동일 단원 버전으로 짝지음.

13 플랫폼 개발팀: 홈페이지 디자인·UX 파트, 프론트엔드/모바일 파트, 회원·강사 화면 파트, 검색·매칭 파트, 예약·화상 연결 파트, 학습·교재 화면 연동 파트, 다국어·접근성 파트. 기존 운영 홈페이지/테스트99 비교 후 디자인과 실제 기능을 통합.

14 사업 시스템팀: 상품·가격 파트, 예약·수업 이행 파트, 모의 결제 파트, 수수료·강사 정산 파트, 환불·분쟁 파트, 소개·다단계 보상 시뮬레이션 파트, 법률·정책 검토 파트. 실제 결제·보상 지급은 승인 전 금지.

15 품질·운영팀: 교육 정확성 검사 파트, UI·접근성 파트, 화상·양측 접속 검사 파트, 거래·정산 검사 파트, 보안·데이터 보존 파트, 자동화/CI 검사 파트, 실사용 통합 시나리오 파트. 타 팀 자기 검증만으로 완료 인정하지 않음.

16 글로벌 성장·마케팅팀: 경쟁·시장 분석 파트, 다국어 현지화 파트, 콘텐츠/SNS·영상 파트, 광고·검색 파트, 강사·파트너 모집 파트, 제휴·아웃소싱 파트, 전환·잔존 데이터 분석 파트.

작동 방식: 총괄이 목표와 통과 조건 제시 → 11팀 실행 엔진이 각 팀장 작업 큐 생성 → 팀장이 파트별 독립 작업 분해·우선순위·의존성 설정 → 파트가 코드/교재/시안/검사 결과 제출 → 팀장 내부 통합 → 15팀 독립 검증 → 실패는 해당 파트로 재전달 → 13팀이 홈페이지 화면 통합, 11팀이 공통 기술·배포 안전 관리 → 총괄이 사용자 여정 검증과 대표 보고.

필수 공통 산출물: task_id, team_id, part_id, 목표, 현재 코드/화면, 변경 파일/콘텐츠, 테스트, 증거, 타 팀 의존성, 판정(PASS/RETRY/BLOCKED), 다음 작업. 같은 기능을 두 팀이 임의로 변경하지 않도록 단일 소유자 지정.

실증 조건: 자동화가 실제로 6개 팀장 작업을 생성하고 최소 2개 이상의 전문 파트가 별도 산출물을 제출하며, 15팀이 독립 반려·재검사를 수행하고, 총괄이 통합 결과를 확인해야 '피라미드형 AI 조직 작동'으로 인정한다. 단순 문서·예약 보고는 불합격.
