# 대표 최종 지시: 모든 개발 진척은 테스트용99에 반영 — 2026-10-29

## 절대 기준
한글쉽지에는 기존 운영 홈페이지와 별도의 **테스트용99**가 이미 있다. 테스트용99는 대표의 최종 승인 전에 모든 기능을 직접 확인하는 유일한 사용자 수락 환경이다. **모든 160개 과제는 코드 구현→독립 CI→테스트용99 반영→실제 브라우저 기능 확인→대표 최종 승인 순서로 관리한다.** 테스트용99 미반영은 코드 검증 완료일 수 있어도 최종 완료가 아니다.

## 즉시 수행할 탐색
11 기반 HQ와 13 플랫폼 HQ는 저장소 모든 브랜치, GitHub Actions 환경/배포 기록, Pages 설정, 호스팅 구성, README, 기존 테스트99 식별 브랜치 `team11/d1-staging99-identity-20261028` 및 `integration/issue4-staging-preview-20261028`에서 테스트99의 **실제 URL, 인프라, 배포 브랜치, 실행 서버/DB, 인증 방식, 기존 배포 SHA**를 찾아 증거와 함께 정본에 기록한다. 임의 URL을 만들거나 추측한 경로를 테스트99라 주장하지 않는다. 운영 홈페이지 URL `https://anigio2705-dev.github.io/hangeul-swipji/`와 혼동하지 않는다.

## 배포/승인 정책
대표는 **테스트용99에 검증된 개발 성과를 반영하는 목적을 승인**했다. 다만 운영 홈페이지, main, 운영 DB, 실결제 및 대외 제출 변경은 여전히 금지한다. 테스트99의 환경이 실제 운영 인프라와 격리되어 있고 테스트 전용 자격증명/DB를 사용한다는 사실을 확인한 후에만 자동 반영을 허용한다. 검증 전에는 테스트99에 위험한 코드나 실결제 경로를 밀어넣지 않는다.

## 6팀 필수 인수 조건
- 11팀: 테스트99 URL·배포 설정·버전 표식·격리/롤백 검증
- 12팀: 교육·음원·퀴즈·읽기 변경의 테스트99 실사용 확인
- 13팀: 화상·매칭·인증·예약 변경의 테스트99 기능 확인
- 14팀: 강사·추천·정산·환불의 테스트 전용 시나리오 확인(실결제 금지)
- 15팀: 테스트99 실제 배포 SHA ↔ 코드 변경 SHA 매칭, PC·모바일 독립 E2E, 실패 시 반려
- 16팀: 언어 전환·글로벌 사용자 흐름의 테스트99 검증

## 필수 보고 항목
테스트99 정확한 URL, 접속 성공/실패, 배포 SHA, 이번 반영 과제 번호, 화면에서 재현한 증거, 반영 실패/차단 사유, 대표 승인 대기 목록. URL을 찾지 못하거나 배포되지 않았으면 **테스트99 미확인/미반영**이라고 명시하고 해당 원인 해결을 최우선으로 삼는다. 코드 커밋/CI만으로 '테스트99 적용'이라고 보고하지 않는다.
