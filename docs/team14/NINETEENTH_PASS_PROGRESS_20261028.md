## 실제 개발
- `phase3/team14_team11_db_adapter.py`: Team11 `phase3/schema.sql`의 `users`/`bookings` 컬럼을 기반으로 SQLite read-only 조회. `read_server_booking(path,booking_id,month_id,lesson_id,authenticated_event=False)`는 DB에서 예약 학생/강사 ID, 강사 역할·승인, 예약 상태를 조회. `read_server_referral_parent(path,learner_id)`는 실제 `users.referred_by` 조회. 인증 이벤트 여부는 서버 이벤트 검증 호출자가 별도로 증명해야 하며 기본 False.
- `phase3/test_team14_team11_db_adapter.py`: 신규 9개 SQLite DB 조회 테스트. 실제 Team11 스키마 컬럼과 동일한 최소 테이블을 구성해 조회·승인 취소·예약 취소·추천인·미존재 계정·재접속을 검사.
- `.github/workflows/team14-monthly-tests.yml`: 기존 120개 예상 테스트 유지 + 신규 9개 = **129개 예상 테스트**. 테스트 삭제/완화 없음.
