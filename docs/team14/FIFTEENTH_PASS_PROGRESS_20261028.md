## 팀 간 실제 연결 상태 및 요구 계약
- **13번→14번: 미연결**. Team13은 서버 내부에서 다음 콜백을 제공해야 함:
  - `read_event(event_id)`: `{event_id,month_id,lesson_id,booking_id,transaction_id,action,booking_status,currency,amount_krw,learner_id,teacher_id}` 반환. DB에서 인증된 이벤트만 반환해야 함.
  - `resolve_booking(booking_id)`: `{booking_id,month_id,lesson_id,learner_id,teacher_id,teacher_approved,booking_status,authenticated_event}` 반환. 반드시 서버 DB/인증 기반, 클라이언트 주장 불신.
  - Team14 함수: `consume_internal_lesson_event(store,event_id,read_event,resolve_booking)`. 재전송은 같은 `event_id`/transaction_id로 호출.
- Team11 인증·예약/강사 승인 DB 조회는 Team13 조회 함수 내부에서 적용 필요.
- Team15은 비운영 통합 브랜치에서 실제 Team13 저장소 조회 함수를 Team14 소비 함수에 전달하여 DB/HTTP/재시작 결과를 검증해야 함.
- **가상 콜백 기반의 Team14 독립 테스트는 실제 Team13 DB 연결을 증명하지 않음.**
