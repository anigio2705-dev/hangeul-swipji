# 56번 — 사람 녹음 품질·확보 기준 (개발 계약 / 외부 승인 전)

이 문서는 사람 목소리 발음 자료의 **후보 확보·기술 검사** 기준이다. 실제 녹음 확보·저작권 확인·청취 승인·공개 사용을 의미하지 않는다.

## 화자
실제 한국어 화자가 직접 발음한 음성만 허용한다. 합성음(TTS), 출처 불명, 동의 확인 불가 파일은 보류한다. 화자 식별자(개인정보 최소화), 녹음 동의, 녹음일, 음원 출처 URL을 별도 관리한다.

## 발음
표준 한국어 발음과 음절·자음 이름을 구별한다. 항목별 발화 문구와 화면 글자가 일치해야 한다. 독립 검수자가 두 번 청취하고 오발음·중복·음절 혼동을 기록한다. 발음 품질은 파일 존재만으로 승인하지 않는다.

## 속도
학습자용 한 글자 발음은 또렷한 자연 속도로 두 번 반복하고, 반복 사이 700ms 휴지를 권장한다. 기계적 배속으로 발음 품질을 보정한 음원은 별도 보류한다.

## 무음
발화 전후 무음과 과도한 잡음을 검사한다. 권장 선행·후행 무음은 각각 100~500ms, 전체 음원 내 장시간 무음은 재검수한다. 자동 길이 검사만으로 청취 승인하지 않는다.

## 파일 형식
원본은 비압축 WAV(PCM, 44.1kHz 또는 48kHz, 16bit 이상, 모노 권장)를 우선 보존한다. 웹 제공본은 실제 브라우저에서 지원하는 OGG/MP3 등으로 별도 변환하고 파일 무결성·재생·음량을 검사한다. 원본과 배포본의 출처·버전을 연결한다.

## 확보
후보는 실제 녹음, 명시적 이용 허락을 받은 제휴 제공자, 또는 사용 조건을 확인한 Wikimedia Commons 등에서 찾는다. 검색 결과는 후보일 뿐 승인 음원이 아니다. 파일별 라이선스·저작자·원문 링크·상업적 이용 및 2차 가공 허용·표시 의무를 확인하고 불명확하면 보류한다.

## 저작권·승인
외부 라이선스 및 화자 동의를 검증하지 않은 파일을 운영 서버에 배포하지 않는다. 사람 청취 검수와 PC·모바일 재생 확인은 별도 승인 단계다. 실제 사람 음성 359개 확보·녹음 완료로 표시하지 않는다.

## 개발 인수 기준
- `scripts/find-human-audio-sources.py`의 후보 검색은 승인 상태를 절대 자동으로 참으로 만들지 않는다.
- 검색 네트워크 오류는 실패로 기록하고 다른 출처가 확인됐다는 추정을 금한다.
- 검색 후보의 메타데이터를 위 기준에 따라 분류하는 로직·독립 테스트를 구현한다.
- 승인된 격리 브랜치에서 단일 파일 변경, 자동 회귀, 15팀 독립 검증 후 코드 검증 단계로 승격한다.
