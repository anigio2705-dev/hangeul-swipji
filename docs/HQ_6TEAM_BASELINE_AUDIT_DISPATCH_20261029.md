## 총괄 수합 기준
1. 여섯 팀 각각 '현재 구현/현재 보이는 결과/누락·오류/기존 자산 보존/신규 제작/우선순위/팀 간 연결/테스트99에서 확인할 화면'을 제출.
2. 교육팀은 교재 품질을 최우선 실질 평가: 350단원과 96수업 전수, 학생·강사용 교재, 발음, 교육 효과. 단순 파일 수 확인 금지.
3. 플랫폼팀은 무료 학습→유료 전환→매칭→양방향 화상→수업 완료의 실제 클릭 흐름을, 사업팀은 거래·정산·소개 보상의 실제 흐름을 대조.
4. 15팀은 각 팀 결과를 독립 재검증하고 총괄은 실패 항목을 해당 팀에 재배정.
5. 16팀은 시장·홍보·파트너/강사 확보를 실제 사이트 전환 기능과 연결.
6. 현재 작업 중지 지시는 유지: 조사 지시서를 저장했지만 자동화 재활성화, 팀별 AI 실행, 테스트99 배포를 했다고 주장하지 않는다. 대표의 재개 지시를 받은 후 실제 병렬 실행 및 결과 수합.
