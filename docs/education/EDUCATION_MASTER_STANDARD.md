# 한글쉽지 공통 교육 기준 (2026-10-27)
## 적용 범위
무료 한국어 2차와 별도 강사용 3차가 공통으로 참고하는 **교육 설계 기준**이다. 이 문서는 기존 교육 콘텐츠를 대체하거나 2차와 3차 코드를 합치는 지시가 아니다.
- 무료 교육: 기존 350단원, 퀴즈 1,758개, 읽기 600개 보존. 정확성과 난이도, 발음 재생 품질을 개선한다.
- 강사용 교육: 별도 교재, 지도안, 학습자 진단, 과제, 피드백 및 평가를 설계한다.
- 강사용 3차 개발 브랜치와 운영 DB를 건드리지 않는다. main 병합은 별도 승인 전까지 하지 않는다.

## 교수·학습 공통 원칙
1. 진단으로 현재 언어 수준과 학습 목적을 확인한다.
2. 수업마다 관찰 가능한 의사소통 목표를 정한다.
3. 도입→시범/이해→안내된 연습→실제 상황 활용→피드백/복습의 흐름을 사용한다. 학생 수준에 따라 조절한다.
4. 듣기·말하기·읽기·쓰기를 분리 진단하고 실제 의사소통 수행과 연결한다.
5. 교사는 학습자 오류를 기록하고 다음 차시 보충활동으로 연결한다.
6. 아동 대상 수업은 연령, 정서, 학습 한국어와 생활 한국어의 차이를 고려한다.
7. 강사에게는 목표, 준비물, 교사 발문 예시, 예상 오류, 채점 기준, 대체 활동을 제공한다.
8. 자동 채점만으로 말하기·발음의 교사 검수를 완료했다고 표시하지 않는다.
9. 정부·공공 교재는 교수법 및 교육과정의 **참고자료**로만 활용하고, 본문·그림·문제를 무단 복제하지 않는다.
10. 모든 콘텐츠 변경은 원본 보존→검사→수정→재검사→근거 기록을 따른다.

## 자료의 근거
- 국립국어원 『초등학생을 위한 표준 한국어: 학습 도구 5~6학년용』 교사용 지도서: 단원 개관, 목표, 어휘, 차시 흐름, 교사 발문, 놀이·협동 학습 및 복습 활동의 구성 참고.
- 충청남도교육청 중도입국학생 한국어교육 절차 자료(2023): 진단평가→강사 지원/배정→교육 운영→결과 보고 흐름 참고. 당시 행정 절차와 단가는 현행 제도로 간주하지 않는다.
- 국립국어원 표준 한국어 고등학생용 전자책 링크: 원문 전체 검토 전까지 출처만 등록.
- 사용자가 제공한 유아 평가도구 및 초등학교 압축자료: 세부 파일별 검토와 사용권 확인 전까지 활용 범위 확정하지 않는다.
