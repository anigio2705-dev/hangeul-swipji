# 교육부 계열 온라인 한국어 학습 프로그램 참고 기준

## 원본 링크
- 한국어 학습 플레이어: https://korean.edunet.net/lms/content/play.do
- 교육 사이트: https://korean.edunet.net/

## 한글쉽지에 참고할 내용
이 링크는 사용자가 직접 제공한 **온라인 학습 프로그램 참고자료**이다. 무료 한국어 2차와 강사용 3차 모두 교육 설계 단계에서 참고한다.

1. 학습자가 수업을 찾고 시작하여 학습을 진행하는 흐름
2. 설명, 예시, 듣기/발음, 연습 문제, 정답 확인, 복습의 연결 방식
3. 학습 진행도·완료 조건과 학습자 피드백의 사용성
4. 초보 학습자가 스스로 수업을 따라갈 수 있는 화면·상호작용
5. 강사가 수업 시범과 지도안을 설계할 때 활용할 수 있는 교수·학습 순서

## 실제 구현 시 확인할 사항
- 플레이어 접근 및 로그인 조건, 모바일·PC 작동 여부
- 화면별 기능과 버튼의 실제 동작
- 오디오 재생, 학습 완료 처리, 평가 결과의 저장·재진입
- 한글쉽지 무료 350단원/1,758문항/읽기 600개와의 차이
- 강사용 독립 교재·지도안·피드백 도구로 옮길 수 있는 **원리**와 독자 구현 범위

## 저작권 및 검증
- 외부 서비스의 소스 코드, 음성, 영상, 그림, 문제와 본문을 허가 없이 복제하거나 GitHub에 업로드하지 않는다.
- 이 문서는 링크와 참고 관점을 등록한 것이며 **실제 전 화면 기능 검증 완료를 뜻하지 않는다**.
- 직접 열람이 막히는 기능은 '미확인'으로 기록하고 임의로 구현됐다고 보고하지 않는다.
- 한글쉽지의 기존 교육 데이터와 운영 DB, 2차 main 및 3차 브랜치를 이 참고자료 등록 작업으로 변경하지 않는다.
