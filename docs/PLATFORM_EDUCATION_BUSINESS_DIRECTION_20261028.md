# 한글쉽지 사업·교육 최우선 방향 (2026-10-28)

> 사용자 최신 지시를 반영한 총괄 기준 보충 문서. 기존 GLOBAL_MASTER_PLAN.md 및 160개 실행표를 대체하지 않는다. 미확정 사업 조건은 확정하지 않는다.

## 1. 사업의 본질
한글쉽지는 전 세계 이용자가 한국어를 **실제로 배우고 사용할 수 있게 하는 교육 플랫폼**이다. 무료 독학, 한국인 회화 파트너와 전문 강사의 유료 수업, 수업 이행·교재·평가·피드백·예약·환불·정산이 하나의 학습 여정으로 연결된다. 교육의 효과와 사용성이 최우선 경쟁력이다. 학교별 초·중·고 과정이 아니라 학습자의 한국어 능력과 학습 목적에 맞춘다.

## 2. 교육 품질을 판단하는 기준
- 무료 350단원·1758퀴즈·읽기600개·별도 읽기문항과 전문 96수업·288내용 확인 문항을 보존한다. 원고 존재, 실제 앱 제공, 사람 검수, 학습 효과는 별개다.
- 한글 자모 조합, 실제 사람 발음, 듣기·말하기·읽기·쓰기, 반복 학습과 진도 기록이 모두 실제로 작동해야 한다. 음원 누락·재생 실패·청취 미승인을 구분한다.
- 학습 흐름: 진단→목표→시범·이해→안내 연습→실제 의사소통 수행→피드백·재진단. 단순 객관식 정답만으로 한국어 구사 능력을 인증하지 않는다.
- 학생용 자료와 강사용 지도서·발문·예상 응답·오류 교정·평가표를 구분한다. 다운로드와 실제 수업 사용성을 검증한다.
- 사용자가 제공한 국립국어원·KSL·유아 평가·초등 압축자료·에듀넷 참고자료를 출처 등록부와 대조해 **미검토 파일은 미검토로 표시**하고 교육 원리를 독자적으로 반영한다. 제3자 저작물은 허가 없이 복제하지 않는다.
- '경쟁 서비스보다 좋다'는 주장은 객관적인 사용성·발음 정확도·학습 성과·강사 지도 품질 비교 후에만 한다.

## 3. 참여·수익의 기본 구조
- 학습자는 무료로 배우거나 강사/파트너의 유료 수업을 선택한다. 강사는 실제 이행한 수업에 대한 보수를, 플랫폼은 승인된 수수료를 받는다.
- 강사와 학습자 모두 다른 학습자 또는 강사를 소개할 수 있다. **소개 혜택은 학습 성적 향상과 별개**이며 학습 실력 미향상을 이유로 소개 혜택을 박탈하지 않는다.
- 직접 소개와 여러 단계 소개 관계는 사업 설계 대상이다. 소개 깊이·요율·기한·보상 재원·거래 조건·환불 후 회수는 미확정이다. 모집 자체 보상이나 가입비 중심의 보상 구조를 확정·구현·지급하지 않는다.
- 소개 구조는 대상국의 방문판매·다단계판매·피라미드 금지 규정, 소비자보호, 세금, 결제·송금 규제의 법률 검토를 거쳐 승인한다. 실제 교육 거래·수업 이행·취소/환불에 따른 보상 확정 및 역분개를 추적한다.
- 유료 월 과정에서 미이행·보강·강사 교체·부분 환불·강사 보수·플랫폼 수수료·소개 혜택의 정합성을 확보한다. 실제 결제/정산은 별도 승인 전 활성화하지 않는다.

## 4. 160개 실행과 우선순위 판단
- 160개 번호를 그대로 유지한다. 새로 번호를 쓰지 않고 기존 구현은 근거 확인 후 재작업하지 않는다.
- 우선순위는 사용자 언급 순서가 아니라 **학습 가치·기반 의존성·사용자 피해 위험·독립 개발 가능성**을 기준으로 총괄이 정한다.
- 이미 구현한 배포·자동 매칭은 재개발하지 않는다. 실제 양방향 통화 검증은 미완료로 기록하되 후속 통합 검증으로 예약할 수 있다.
- 공통 파일과 DB 스키마는 동시 수정하지 않는다. 각 Work의 브랜치·담당 파일·기준 SHA·검사 결과를 총괄이 확인하고 통합은 순차적으로 진행한다.
- 기존 홈페이지, 무료 콘텐츠, 운영 DB, main, 실제 결제·정산은 승인 없이 변경하지 않는다.
- 완료 판정은 코드·자동 검사·공개 배포·실제 기기·교육 검수·운영 승인을 구분한다.

## 5. 아직 검증해야 할 사실
참고자료의 세부 전수검토, 발음 전 항목의 실제 사람 음원과 청취 승인, 교육과정의 실제 학습 효과, 공개 서비스의 두 기기 양방향 통화, 영구 DB/실제 금전 흐름, 소개 보상 구조의 국가별 법적 적합성은 완료로 주장하지 않는다.
