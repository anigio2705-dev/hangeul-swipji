## 반드시 고칠 사항
1. audit-map-01..04에는 800 원본이 1회씩 들어가나 05~06은 빈 공정이며 07~12는 13~15팀 204건의 **추가 교차참조(중복)**이다. 총 1,004개의 독립 원본이 아니다. **고유 원본 800건**.
2. 제목/수정 가설 키워드 매핑은 기능의 실소유 팀과 어긋날 수 있다. 예: 13팀 화상 기능이 '세션' 키워드 때문에 기반 공정으로 분류됨. 수동·코드 기반 재분류 필요.
3. 감사표의 '코드' 칸은 경로가 잘린 요약/추정/브랜치 정보일 수 있다. **실제 코드 파일이 확인되었다고 주장하면 안 된다.** GitHub 파일 트리·정확한 파일 경로·라인·기능 테스트로 확인해야 한다.
4. 600개 실행 지시의 정확한 원문·ID는 아직 미확보. 160개 로드맵도 1:1 매핑 미완료.
5. 1,200 지시 중 다수는 공통 문구가 반복되므로 세부 산출물 수량·원본 파일·정확한 테스트 케이스를 정밀화해야 한다.
6. 실제 Render99 배포 SHA, DB 영속성·백업, 브라우저/실화상 검증 미확인. 실제 수정·배포 완료 0으로 취급.
