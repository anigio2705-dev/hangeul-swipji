## 실행·완료 관리
- 모든 지시의 고유 키 HQ-001-T11 ~ HQ-120-T20. 회차마다 10팀이 병렬 수행한다.
- 각 지시는 실제 GitHub 코드/교재 경로, 원본 감사 ID(800건), 이전 실행 지시 ID(600건), 사업 로드맵 ID(160건)와 **후속 매핑**해야 한다. 기존 800건은 결함 확정 수가 아니며 600건과 중복 가능하다.
- 15팀은 원본 ID 대조, 선행 의존성, 작업 담당, P0, 테스트 증거, GitHub SHA, 실제 Render99 SHA, 인수자를 기록한다. 미검증은 미검증으로 남긴다.
- 18·19팀은 유료 교육과정 전체 레벨/수업 수를 확정한 뒤 교사 지도서·학생 교재·과제·평가를 **같은 lesson_id**로 전수 제작해야 한다. 8회 파일럿만으로 전체 완료 처리 금지.
- 12팀은 음원 미확보 시 기존 파일 조사→재생 결함 분리→사용권 있는 음원/TTS 조사→원어민 신규 녹음 확보→발음·실기기 검수. 타인 음원 무단 사용 금지.
- Render99 배포 전 기존 SQLite DB 백업/복원 및 권한 확인. 기존 정상 매칭·화상 경로 보존. 실제 결제는 별도 승인.
- 최종 게이트: 무료350/퀴즈1758/읽기600/8언어/발음439, 유료 전체 교재, 실제 2기기 화상, 과제·평가, 모의거래·환불, 학생·강사·관리자, P0=0, 실서버 SHA 및 증거.
