작성일 2026-10-28. **기존 문서·코드·원본 800건 보존, 추가 전략**. 조사 출처: docs/audit/team11-99-gap.md (70), team12-99-gap.md (526), team13-99-gap.md (110), team14-99-gap.md (64), MASTER-99-GAP-BACKLOG.md (팀15 30). **아래 '팀 제안'은 원본 보고서의 발견에서 총괄이 도출한 제안이며 해당 팀과 별도 토론·승인한 발언이 아님.** 본 문서만으로 실서비스·매출·시장성 검증 완료 아님.

## I. 최종 목표
세계인이 한국어를 쉽고 재미있게 배우고 한국인과 안전하게 만나 대화·교류하고, 원하면 회화 파트너 또는 전문 강사의 유료 수업을 구매한다. 강사는 실수업으로 돈을 벌고, 학생은 실력과 관계·경험을 얻고, 크리에이터·소개자는 검증된 실제 거래 기여에 대해 합법적 보상을 받고, 플랫폼은 수수료·재구매로 지속적인 공헌이익을 얻는다. 무료학습/콘텐츠→사람과의 만남→유료수업→재구매→추천·콘텐츠 확산→신규 이용자의 순환이 핵심 제품이다.
성별/국적별 교류 관심을 활용하되 만남·데이트를 교육이라고 위장하지 않는다. 대화·친구·학습의 목적을 명시하고 성인/동의/신고/차단/사기 방지 기능을 설계한다.

## II. 기존 다섯 조사팀에서 뽑은 사실과 사업 관점 제안
### 11 공통 기반팀 (70)
**원본 사실**: server.py 회원·학습·예약·관리 API, schema.sql 저장 스키마 존재. Render99 현행 배포 SHA, 관리자 실접속, SQLite 영속성·백업/복원 미확인. 원본 11-S001~070.
**총괄 도출 제안**: 기존 서버 보존/백업→회원·진도·수업·결제·소개 이벤트를 동일 사용자/거래 ID로 연결→가입·결제 이탈/성공 데이터 추적→실서버 검증. 고객/돈 데이터 유실은 사업 중단 위험.
### 12 교육 개발팀 (526)
**원본 사실**: 발음 매핑 미완(19 자음 이름 매핑 0, 21 모음 9, 399 조합 19; 녹음 매핑과 실재생은 별개). 350단원/1758퀴즈/600읽기 전체 실서버 품질은 전수 검증되지 않음. 원본 T12-0001~0526.
**총괄 도출 제안**: 무료학습을 '10분 만에 실제 한국어 한마디→한국인과 말해보기'의 유료 전환 엔진으로 설계. 350단원 전체 품질은 유지하면서 1차에는 대표 학습 경로·발음·진단·대화 연결을 최우선 완성. 무료→유료 전환 계측.
### 13 플랫폼 개발팀 (110)
**원본 사실**: instant_matching.py 큐·매칭·ready·예약/완료 이벤트 코드, instant-speaking.html UI. Jitsi 네트워크 mock 테스트는 실제 2기기 영상·음성 증명이 아님. 원본 T13-001~110.
**총괄 도출 제안**: 무료 5~10분 언어교환 체험(운영 정책 승인 필요)→예약 15/30분 유료 대화/수업, 재예약, 강사 평판. 성인·안전·신고·차단/불쾌행위 대응을 첫 시제품부터 포함. 실제 두 기기 검증을 유료 출시 선행 조건으로.
### 14 사업 시스템팀 (64)
**원본 사실**: server.py 자체 ledger와 별도 MonthlyStore/환불 SQLite, 실제 서버 API 통합 미확인. 원본 T14-001~064. 모의 정산/환불 테스트 성공≠실결제/실지급.
**총괄 도출 제안**: 단일 예약→완료 이벤트→결제→강사 수익→플랫폼 공헌이익→환불→실거래 기반 소개 보상을 한 원장으로 연결. 각 거래별 수익성이 양수인지 자동 계산. 실결제 전 법률/PG 승인.
### 15 품질 운영팀 (30)
**원본 사실**: 통합 CI 후보 SHA 존재하지만 실제 Render99 배포 SHA·실서버 E2E 미확인. 원본 T15-001~030 및 MASTER 800.
**총괄 도출 제안**: 코드 기능별 QA를 넘어 방문→무료학습→사람과 대화→유료 수업→정산→재구매→추천의 실제 고객·매출 여정을 한 번에 검증. 각 실험의 실패 원인·예산·전환 수치까지 인수.
### 총괄의 독립 추가 제안
1. **무료 학습은 상품이 아니라 유입/신뢰 엔진**: 방문 1분 내 '한글 읽기/첫 문장' 경험.
2. **한국인과 대화하는 재미**: 단순 교육 외 문화·관심사 기반 대화, 안전한 무료/유료 구분.
3. **공급자 확보**: 일반 한국인 회화 파트너 vs 자격/경력 검증된 전문 강사 2개 상품.
4. **강사도 영업 동기**: 본인 프로필/수업 링크/크리에이터 콘텐츠로 수강생 확보, 실수업 수익과 재예약.
5. **소개 확장**: 한 단계의 실제 유료 거래 추천·크리에이터 제휴 우선. 다단계 보상은 한국 및 대상 국가 규제·등록/금지 여부 전문 검토 전 도입하지 않음. 무한 하위 모집 보상은 금지.
6. **광고를 개발과 동시에**: 국가별 유입 채널/메시지/가격 가설을 소액 실험으로 검증.
7. **단위경제 우선**: 회당 가격 P - 강사 보수 T - 결제비용 F - 환불·지원 R - 소개 보상 A = 건당 공헌이익. 광고 획득비(CAC)는 재구매를 포함한 고객 공헌이익으로 회수해야 함.

## V. 첫 6주 병렬 실행안 (기간은 가정, 확정 일정 아님)
**주 1** 25: 800감사/160/600 원본 연결, 기존 코드 기능·실서버 배포 상태 표. 16: Render99 SHA/DB 백업 확인. 22: 상품 3안 단위경제. 23: 고객 국가·고객군 2개 선정, 광고 메시지/랜딩 3안. 21: 안전/강사 모집 정책.
**주 2** 17/18/19/20: 대표 무료→유료 학습경로/교재/진도 연결. 21: 2기기 매칭·화상 테스트. 22: 모의거래/환불/추천코드 연결. 23: 랜딩·추적 이벤트. 24: 전체 E2E 설계.
**주 3~4** 통합·회귀·실서버 검증, 성인 파일럿 모집, 무료→유료 제안·가격·메시지 실험. 광고는 서비스 안전/동의/실제 경로 준비 후 소액 시작.
**주 5~6** 고객 인터뷰, 재예약·추천 성과 확인, CAC/완료율/환불/강사 수익 비교, 실패 채널·기능 수정, 2차 범위 승인. 실제 소요는 팀 역량·접근 권한·실사용 모집에 따라 달라진다.

## VI. 광고 연구의 구체적 실험
초기 2개 시장/언어를 데이터로 선정. 채널 A 검색·SEO, B 유튜브 쇼츠/틱톡/릴스, C 한국어 크리에이터·언어교환 커뮤니티 제휴. 라디오/대규모 브랜드 광고는 추적 가능한 유입 효율이 확인되기 전 보류. 각 채널에 방문수, 가입률, 첫 학습률, 첫 유료 구매율, CAC, 30일 재구매, 신고율을 기록. 광고는 일일/주간 예산 상한·중단 기준 승인 후 집행. 초기에 유료 수업 경로가 불안정하면 대규모 광고 금지.

## VII. 수익 가설과 검증
상품 A 즉시 15분 대화, B 예약 30/60분 수업, C 월 4회 묶음. 수수료·강사 보수·소개보상은 확정 전 3개 가격 시나리오로 비교. 예시 P=20,000원, 강사 T=13,000원, 결제 F=700원, 환불/CS R=500원, 소개 A=1,000원 → 공헌이익 4,800원/회(광고/고정비 전). 예시이지 가격 결정 아님.
목표 지표는 '방문→첫 학습→유료 구매→완료→재구매→소개'의 단계별 전환, 유료 수업당 공헌이익, CAC 회수기간, 강사 순수익/시간, 안전/환불. 데이터 없는 목표 숫자를 실적으로 기록 금지.

## VIII. 사업의 가장 큰 위험 및 대응
- 고객이 오지 않음 → 광고 채널/콘텐츠/시장 실험을 개발과 병렬 운영.
- 고객이 무료만 이용 → 첫 성취 후 실제 한국인과 말하기 제안·가격/시간 실험.
- 강사가 부족 → 강사 모집·수익 시뮬레이션·초기 공급시간 확보.
- 화상 품질 불량 → 실제 2기기/모바일 검증, 실패 환불/재예약.
- 유료 결제는 되나 플랫폼 손실 → 거래별 공헌이익/광고비 대사.
- 소개제도가 규제/사기 위험 → 단층 실제 구매 추천부터, 국가별 법률 검토, 위조/자기추천 차단.
- 교류에서 불쾌행위·안전 사고 → 성인 인증 정책, 신고/차단, 운영 검토, 미성년 보호.
- 배포/DB 데이터 유실 → 백업/복구/배포 SHA 확인 전 변경 금지.

## IX. 총괄 운영·인수 규칙
총괄이 차수별 제품·광고·매출 목표/예산 승인 → 25가 원본ID·업무ID 연결 → 22/23 시장·가격 가설 작성 ↔ 16~21 기능 구현 → 24 실제 배포/브라우저/2기기/거래/안전 E2E → 23 소액 실사용 실험 → 25 전환/재구매/공헌이익 보고 → 총괄 확대·수정·중단 결정.
각 업무: 원본ID, 실제코드, 소유팀, 가설, 고객/수익 기여, 의존성, 테스트, 배포SHA, 성과지표, 증거, 차수, 다음 행동. 기존 문서 삭제/기존 코드 무단 배포 금지.
**중요한 구분**: 원본 5팀은 기술 실사 보고서를 작성했다. 여기서 파생한 사업 아이디어는 총괄의 재구성이지 다섯 팀이 독립적으로 브레인스토밍한 결과가 아니다. 팀별 독립 아이디어 제안은 추가 과제로 남는다.
