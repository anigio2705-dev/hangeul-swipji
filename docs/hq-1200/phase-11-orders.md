# 공정 11 — Render99 통합·회귀 (101~110회차)

각 행은 **작업 명령**, 완료 선언이 아니다. 10팀은 같은 회차에서 병렬 실행한다. 선행 입력이 없으면 즉시 차단 ID를 기록하고 독립 작업을 먼저 수행한다. 원본 ID 매핑과 실제 Render99 배포 SHA가 없는 작업은 완료 처리 금지.
