## 전 팀 공통 제출 규격
1. 기존 계획의 오류/반론 3개
2. 독립 제안 5개 이상: 대상 고객, 사용 동기, 돈이 생기는 방식, 교육/기술 가치, 실제 코드 경로, 난이도, 비용, 위험, 우선순위, 실험/중단 조건
3. 1차~4차 **모두 전체 사업 흐름**을 포함한 점진적 개선
4. 가장 짧은 현실적인 실행 순서, 타 팀 의존성, 2/4/8주 일정 가정
5. 다른 4팀에 질문 3개, 총괄에 결정 요청 3개
6. 실제 보고서 커밋·증거·원본 ID 연결

## 총괄 수집 후 할 일
5개 독립 제안이 제출되어야 비교표를 만든다: 신규 고객 유입, 첫 유료 구매, 강사 수익, 플랫폼 공헌이익, 재구매, 소개 확장, 학습 성과, 안정성, 개발 시간/비용, 법률 위험. 아이디어를 그대로 합치지 않고 중복 제거·상호 비판·우선순위 결정. 기존 800/160/600 기록은 보존한다. 실제 팀 연구가 제출되기 전에는 **합의/완료/최종 계획**이라고 부르지 않는다.
