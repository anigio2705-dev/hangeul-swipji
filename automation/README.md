# 한글쉽지 자동 총괄본부 — 13·14·15팀 시범 운영

## 허용 범위
이 브랜치는 13·14팀 최신 소스와 15팀 검증 환경을 **읽기 전용**으로 가져와 예약 상품 계약을 검증합니다. GitHub Actions의 읽기 전용 권한(`contents: read`)을 사용합니다. main 병합, 99 서버 배포, 운영 DB 접근, 실결제 및 GitHub Issue 자동 수정 기능은 없습니다.

## 실제 구현
- `.github/workflows/hq-pilot-13-14-15.yml`: 브랜치 변경 또는 수동 실행 시 최신 팀13/14/15 브랜치를 별도 폴더로 체크아웃하고, 예약 회귀 및 가격·환불 HTTP/SQLite 교차 테스트 실행.
- `automation/hq_pilot.py`: 테스트 결과에 따라 blocked/waiting/code_passed/ready_for_review를 결정하고 오류 소유 팀을 분류하는 **결정 로직**. 실제 GitHub 이슈 생성·팀 호출·코드 자동 수정은 아직 연결하지 않았습니다.
- `automation/test_hq_pilot.py`: 실패/누락/대기 증거를 승인하지 않는지 검증.

## 비용과 제한
GitHub Actions 실행 시간은 계정의 Actions 할당량을 소비할 수 있습니다. Codex/Work는 이 파일들에서 호출하지 않습니다. 초기 시험은 수동 또는 시범 브랜치 변경 시만 실행하며 주기적 폴링과 무한 재시도는 없습니다.

## 판정 규칙
- 단독 테스트 성공 + 공동 계약 실패 → 13·14팀 재작업 후보
- 증거 누락/진행 중 → 대기, 완료 금지
- 모든 코드 검사 성공 → 코드 검증 통과, 99 서버 검증은 별도
- 99 서버 검증까지 완료 → 대표 승인 요청, 자동 D3 진입 금지

## 확대 전 남은 작업
GitHub CI 완료 이벤트를 안전하게 수집하고, 결과 보고서를 자동 게시하는 기능, 작업 큐/중복 방지/실행 한도, 승인된 AI 실행기 연결 및 예산 통제는 **아직 미구현**입니다. ChatGPT의 여섯 대화창을 자동으로 실행시키는 시스템이 아닙니다.
