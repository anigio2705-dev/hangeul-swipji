# 화면에서 발견한 연결 결함 수리 범위

실제 Chromium의 가입→승인→예약→모의결제→과제/피드백→수업완료→모의정산 흐름은 진행됐지만 환불에서 기존 상대방 진술 요건 때문에 멈췄다. app.js에는 진술 조회/입력 화면이 없어 API에서 가능한 정상 절차를 사용자가 수행할 수 없었다.

수리 범위: phase3/app.js에 예약 당사자의 기존 진술 API 조회·추가 화면과 관리자의 읽기 화면만 연결. 기존 서버의 상대방 본인 진술/권한/환불 검사를 유지한다. HTML escaping, 계정 전환 후 늦은 응답 차단을 보존한다. 독립 검토 및 실제 UI 재검사가 필요하다. 운영/현재24시간시험에는 적용하지 않는다.
