## 사용자에게 보이는 변경

site-language.js가 페이지 안으로 외부 번역 JavaScript를 자동으로 넣지 않도록 변경했다. 자체8개 언어 수업 메뉴, 무료 과정의 기존 한국어/영어 처리, 언어 선택·저장·이동과 공부하는 한국어의 번역 제외는 유지한다.

기계 번역은 사용자가 누르는 '공개 페이지 번역' 링크로 별도 탭에서 제공한다. **기존 화면의 본문 자동 번역은 별도 탭 방식으로 변경된다.** 학습·계정은 원래 탭에서 이용하도록 안내한다. 외부 링크에는 공개 페이지 경로와 선택 언어만 전달하고 기존 쿼리/fragment는 제거한다. 새 탭은 noopener/noreferrer/no-referrer로 연다. 로컬 주소에는 외부 번역 링크 대신 브라우저 번역 안내를 표시한다. 외부 번역 서비스 자체의 가용성·품질·로그인 수업 지원은 이번 검사에서 인증하지 않는다.
