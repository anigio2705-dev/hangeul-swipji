# 3차 교육 프로그램 참고 조사

조사일 2026-10-26. 교육부/세종학당의 학습 구조를 참고하고 독자 콘텐츠를 설계한다. 자료·음원·이미지·문항·캐릭터·UI 코드를 복사하지 않았다. 조사 내용은 실제 구현·교육 효과 검증과 구분한다.

## 교육부/KERIS ‘모두의 한국어’: 브라우저에서 직접 관찰

- https://korean.edunet.net/lms/content/play.do 에 직접 접속하면 **‘잘못된 접근입니다.’** 대화상자가 표시됐다. 확인 후 홈과 공개 서비스 소개를 조사했다. 로그인이나 강좌 신청 없이 본 수업 플레이어를 끝까지 실행하지 못했다. 따라서 실제 음성 인식 정확도·학습 저장·교사 대시보드·퀴즈 채점·모바일 성능은 이번 조사에서 검증되지 않았다.
- 홈 https://korean.edunet.net/ 에서 ‘모두를 위한 한국어’, ‘문법쑥쑥’, ‘어휘쑥쑥’, ‘한국어 예비과정’ 탭을 관찰했다. 샘플은 수준·단원·차시와 학습 목표, 말하기/듣기/쓰기/읽기/웹콘텐츠 범주를 함께 표시한다.
- 소개 페이지 https://korean.edunet.net/lms/cm/mcom/intro.do 는 한국어에 익숙하지 않은 **학생** 대상이며 자가진단/능력검사→맞춤 추천→상호작용 학습 흐름을 설명한다. 말하기·선택·연결 활동, 사전/번역 보조를 화면에서 관찰했다. ‘130개 언어 페이지 번역, 10개 언어 TTS’는 사이트의 표시 문구이며 전 언어를 직접 시험하지 않았다.
- 홈 캐러셀은 움직여 최초 관찰한 샘플 링크가 클릭 시 사라졌다. 단원 내부 활동을 관찰했다고 주장하지 않는다. 공개 소개까지만 확인했으며 계정·개인정보를 생성하지 않았다.

### 한글쉽지에 적용할 독자 설계

진단은 평가 결과와 근거를 보여주고 무료 학습/권장 수업을 연결한다. 성인에게는 카페 주문·교통·병원·직장·주거·사회적 관계처럼 목적 중심 상황을 사용한다. 어린이용 학교 사례를 성인 과정에 그대로 옮기지 않는다. 준비→짧은 모델 대화→이해 확인→통제 연습→역할극→독립 수행→과제/피드백으로 구성한다. 수준별 글 길이·어휘·문법·추론 요구를 기록하고 실제 학습자 파일럿으로 검증한다. 이 흐름은 독자 제안이며 참고 사이트에서 전체 순서를 실증한 것이 아니다.

## 전문 수업 단원 자료 계약

각 단원은 고유 ID·버전·난이도·목표·선수학습·작성자·권리 정보로 식별한다. 예약은 특정 버전을 고정하고 강사와 학습자가 같은 자료를 연다. 무료350단원/읽기600항목의 파일과 구분한다.

필수 묶음: (1) 강사용 시간 배분·오류 지도·확장·정답·루브릭 (2) 학습자 교재 (3) 독립 읽기 (4) 실제 상황 대화 (5) 어휘·문법·예문 (6) 듣기 대본과 적법하게 제작한 음원 (7) 듣기·말하기·읽기·쓰기 활동 (8) 역할극 (9) 숙제·평가·해설 (10) 피드백·진도 기준.

강사 지침의 정답이 학습자에게 평가 전에 노출되지 않도록 서버 권한이 필요하다. 클라이언트에서 숨기기만 하는 것은 접근 통제가 아니다. 공개 미리보기와 유료 수업 자료도 별도 범위로 관리한다. 음원이 없으면 대본/음원 미제공으로 표시하며 TTS를 사람 녹음이라고 표시하지 않는다.

## 검증해야 할 교육·운영 항목

- 원어민/교사 문법·자연스러움 검토, 수준 인접성, 문항 정답 유일성.
- 실제 초보자 파일럿: 막힌 단계, 소요시간, 목표 달성, 과제 부담, 언어 도움 효과.
- 강사/학습자 2계정으로 동일 버전 열람, 강사 지침 권한 분리, 과제·평가 저장.
- 음원 권리·발음·잘림·모바일/PC 실제 청취. 현재 조사로 완료되지 않음.
- PC/모바일 화면·키보드·대비·자막·접속 장애·느린 회선 검증.
- 매칭/학습 효과·수익성은 프로토타입 구현만으로 입증되지 않는다.

## 검토 결론의 범위

에듀넷의 공개 화면과 세종 공식 자료의 구조를 확인했다. 에듀넷 본 학습 플레이어·교사 계정 내부 조사, 실제 이용자 파일럿, 전체 연령/언어 교육 효과 검증은 미완료다. 3차 Python/SQLite 로컬 테스트 서버가 존재하더라도 Supabase 운영 연동·실결제·정산·지급이 완료됐다는 뜻이 아니다. 기존 2차와의 통합과 main 병합은 하지 않는다.
