# 3차 정책 5종 — 검토용 초안

작성일 2026-10-26. **미승인 초안. 실제 서비스 약관으로 공표·동의 수집하지 않는다.** 로컬 Python/SQLite 테스트 서버와 샌드박스 기록만을 전제로 한다. 기존 Supabase, 2차 무료 학습 데이터 및 main은 변경 대상이 아니다. 실결제·자동 정산·추천 현금 지급 없음. 아래 출시안은 미구현 요구사항을 포함하며, 구현됨을 의미하지 않는다. 법률 근거/미확정 사항은 LEGAL-REVIEW.md를 따른다.

게시 전 반드시 확정할 공란: 운영 법인명/대표자/주소/연락처/사업자등록번호/통신판매 관련 신고, 개인정보 책임자, 계약상 판매자, PG사/국외 수령자/국가, 상품별 환불표, 보상률/한도/기간, 확정 정산일, 국가별 적용 약관, 분쟁 처리 기한. 이 공란이 남으면 운영 게시 금지.

## 1. 이용약관 초안

1. **서비스와 단계**: 한글쉽지는 Learn→Speak→Teach→Earn의 학습·수업 연결을 지향한다. 무료 자기학습과 유료 수업은 별도 서비스다. 현재 3차는 테스트 전용이며 화면의 테스트 금액·거래·보상은 실제 지급 청구권이나 수익이 아니다.
2. **역할**: 학습자는 수업을 신청한다. 회화 파트너는 일상 대화·발음·문화 연습을 제공하며 전문 자격을 보유한 것으로 표시하지 않는다. 전문 강사는 실제 확인된 교육 경력·자격·전문 분야만 표시한다. 관리자는 정해진 권한으로 심사·분쟁 처리를 한다. 역할 선택만으로 신원/전문성 승인이 되지 않는다.
3. **계정과 이용 자격**: 계정 공유·사칭·허위 자격을 금지한다. 향후 유료 파일럿의 연령/국가 제한과 보호자 절차는 별도 고지한다. 테스트 등록은 실제 신원·연령 검증으로 간주하지 않는다. 비밀번호·신분증·금융정보를 수업 게시물이나 과제로 제출하지 않는다.
4. **계약 체결**: 운영 전 판매자/중개자 지위, 당사자 정보, 총 가격·세금·통화, 제공 시간·표준 시간대·교재 버전, 취소/환불 조건을 결제 전에 제시한다. 이용자 신청과 서버 확정으로 예약이 생성되며 중복 시간은 확정하지 않는다. 로컬 테스트 예약은 실제 유료 계약으로 표시하지 않는다.
5. **수업과 자료**: 양측은 동일한 예약·단원·자료 버전을 사용한다. 담당 강사는 학습 목표·과제·평가·피드백을 제공하고 제공한 분량을 기록한다. 회의방 입장이나 한쪽의 버튼만으로 수업 완료·정산을 확정하지 않는다. 교재 열람권은 해당 계약/허락 범위에 한한다.
6. **안전과 권리**: 괴롭힘·성적 접근·혐오·불법 콘텐츠·외부 결제 유도·허위 완료·부정 추천을 금지한다. 녹음·녹화·홍보 사용은 별도의 적법한 근거/권리 확보 없이 허용하지 않는다. 신고·차단·이의신청을 제공하며 안전상 필요한 임시 제한의 이유와 재검토 절차를 안내한다.
7. **취소·환불과 책임**: 강행법상 소비자 권리를 축소하지 않는다. 환불정책에 따른 증빙·조사·결과 통지를 제공한다. 플랫폼과 강사 각각의 법정 책임을 포괄 면책하지 않는다. 시스템 장애의 대체 일정/환불을 안내한다.
8. **변경·해지·분쟁**: 중요한 정책 변경은 적용일/이유/비동의 선택을 사전 안내하고 기존 거래에 불리하게 소급하지 않는다. 계정 종료 시 법정 보존 기록을 제외한 개인정보를 파기한다. 준거법·관할은 한국 사업자를 가정하되 해외 소비자의 강행규정과 적법한 재판관할을 배제하지 않으며 국가별 문안을 법률 검토한다.

## 2. 개인정보 처리방침 초안

1. **범위와 현재 상태**: 로컬 테스트 서버의 계정·예약·과제·테스트 원장에 적용할 개발 초안이다. 운영 개인정보처리자·담당자 연락처가 확정되지 않았으므로 실제 정책으로 게시하지 않는다. 실제 카드정보·신분증·주민등록번호·은행계좌·민감정보를 테스트에 입력하지 않는다.
2. **목적·최소 항목 제안**:

|목적|최소 항목 제안|접근 범위|
|---|---|---|
|계정/인증|이메일 또는 테스트 식별자, 비밀번호 해시, 역할, 세션|본인 및 제한된 운영 담당|
|검색/매칭|공개 표시명, 언어, 시간대, 검증된 소개·전문 분야, 가격·가능 시간|공개 승인 항목만 검색 노출|
|예약/수업|당사자 ID, 일정, 단원/버전, 출석/제공 증빙|수업 당사자와 담당 관리자|
|학습 관리|과제, 평가, 피드백, 진도|해당 학습자·담당 강사, 필요한 관리자|
|결제/분쟁/보상|거래 ID, 상태·테스트 금액, 직접 추천 연결, 증빙·감사 기록|거래 당사자별 최소 보기 및 권한 담당자|
|보안|최소 접속/실패 로그, 세션 시각|보안 담당자|

각 항목의 법적 처리 근거는 실제 운영 목적별로 계약 이행·법률 의무·동의 등 검토해 명시한다. 동의를 모든 처리의 포괄 근거로 사용하지 않는다. 공개 프로필과 신원 심사 자료는 별도 저장한다. 신원 확인은 적법한 전문 제공자를 우선 검토하고 원본 신분증 보관을 최소화한다.

3. **보존·파기**: 목적 달성/탈퇴 시 불필요 정보를 삭제한다. 법률상 필요한 계약·철회·결제·공급·분쟁 기록은 각각의 보존 근거/기간을 표시해 분리 보관한다. 광고6개월, 계약/철회 및 결제/공급5년, 불만/분쟁3년은 시행령6조 적용 범위를 법률 검토한 후 반영한다. 세무·보안·소송 보존 및 백업 파기 주기는 별도 확정한다. 모든 학습 대화의 무기한 보존을 허용하지 않는다.
4. **제공·위탁·국외 이전**: 운영 공급자(호스팅, Supabase, 화상, 이메일, PG)의 업체명/국가/항목/목적/시기·방법/기간/법적 근거와 거부 방법·영향을 확정한다. 지금은 기존 Supabase를 연결·수정하지 않는다. 외부 Jitsi 접속은 해당 제공자의 개인정보 처리에 영향을 받으므로 운영 연결 전 고지·계약·보안 검토가 필요하다. 테스트 링크 생성이 이 절차의 완료를 뜻하지 않는다.
5. **권리와 보호**: 열람·정정·삭제·처리정지·동의 철회 및 대리인 절차를 지원할 연락 창구를 정한다. 아동은 국가별 연령/보호자 확인에 맞춘 별도 쉬운 설명을 제공한다. 개인정보 유출 대응, 접근 통제, 해시·전송 보호, 백업·접근 감사·관리자 인증을 운영 검증한다. 개발용 보안 기능만으로 운영 안전 인증을 주장하지 않는다.
6. **선택 동의**: 마케팅, 녹음·녹화, 홍보 재사용, AI 학습을 필수 수업 동의에 묶지 않는다. 실제 도입 전 목적·항목·기간·거부 영향과 권리 관계를 각각 검토한다. 현재 기본값은 녹음/녹화/AI학습 없음이다.

## 3. 강사·회화 파트너 계약 초안

1. **지위와 승인**: 회화 파트너와 전문 강사를 구분하며 신청/검증/승인 내역을 기록한다. 전문 자격 확인 전 전문 강사 표시를 하지 않는다. 프리랜서라는 명칭만으로 근로자성을 배제하지 않는다. 실제 통제·종속관계·국가별 노무법을 별도 검토한다.
2. **제공 의무**: 예약 당시 공개한 수업시간·목표·교재·언어·서비스 범위를 이행한다. 지각·결석·연결 장애는 즉시 알리고 객관적 제공 기록 및 학습 피드백을 남긴다. 허위 출석이나 학습자에게 완료 확인을 강요하는 행위를 금지한다.
3. **대금과 공개 조건**: 출시 전 거래별 총 수업료, 플랫폼 수수료, 결제 비용 부담, 세금/원천세, 환불 배분, 확정/지급 시점, 통화·환율·송금비를 계약에 표시한다. 개발 중 수익성 시나리오 수치는 확정 계약 요율이 아니다. 선택형 전문 서비스 구매를 강사 활동 자격 유지나 추천 수익 조건으로 강제하지 않는다.
4. **보수 구분**: 제공 완료로 적법하게 확정된 보수, 완료 검토 중인 미확정 금액, 별도 조건을 충족해야 하는 인센티브를 구분한다. 위반 시 자동 벌금·무조건 공제·다른 거래의 보수 상계를 하지 않는다. 분쟁 거래의 보류 범위와 기간은 합리적·공개된 기준 및 적용 법률을 검토한다. 근로자에 해당하면 임금 전액 지급과 위약 예정 금지 등 강행규정을 우선한다.
5. **취소·분쟁**: 결석·미충족·장애는 증빙 제출, 양측 소명, 독립 관리자 검토, 이유 통지, 이의신청 순으로 처리한다. 이미 지급된 정당한 보수를 임의 환수하지 않는다. 부정행위 확정에 따른 청구는 계약과 법률상 근거 및 별도 절차를 따른다.
6. **자료·개인정보**: 창작 자료의 소유권과 플랫폼에 허용하는 비독점 이용 범위/기간/국가/삭제 시 처리를 구체화한다. 포괄 영구 권리 양도를 기본값으로 하지 않는다. 학습자 정보의 외부 이용·연락처 수집·무단 녹화·타 수업 공유를 금지한다. 자료에 사용된 음성·사진·인용 허락을 확인한다.
7. **평가·종료**: 실제 완료 거래의 후기만 연결한다. 부정 평가/보복·허위 신고의 이의 절차를 보장한다. 승인 취소·계약 종료는 사유/예고/안전상 예외/재심 절차를 구체화한다. 세무·지급 기록은 법정 의무에 따라 처리한다.

## 4. 취소·환불·불이행 정책 초안

**아래는 판정 흐름이며 확정 환불률표가 아니다.** 수업 전/후 시간별 환불률, 지급일, 처리 기한은 관할 법령·상품 구조·PG를 확인한 후 구매 전에 고지한다. 소비자에게 불리한 강행규정 위반 약정은 적용하지 않는다.

|상황|초기 처리|판정·금액 원칙|
|---|---|---|
|수업 전 취소|접수시각·예약 정책 버전 저장|법정 철회권과 유효한 사전 고지 기준 검토; 임의 전액 몰수 없음|
|강사 무단결석|미완료, 당사자 통지, 관련 미확정 정산 검토|미제공분 환불 또는 학습자가 선택하는 적절한 재수업; 자동 벌금 없음|
|학습자 결석|강사의 대기/제공 가능성 확인|사전 계약과 강행규정으로 판단; 자동 완료·전액 지급을 보편 규칙으로 하지 않음|
|시간/내용 미충족|제공 분량·학습 목표·양측 소명 확인|미제공분 환불/재수업 등 합리적 시정; 정당한 기발생 보수 구분|
|연결 장애|장애 시각과 당사자별 상황 확인|책임·제공량에 따라 대체 일정/미제공분 환불; 접속 성공만으로 정상 이행 아님|
|부정/차지백|결제사 상태와 원거래 연결, 보상 미확정|원장 역분개와 합법적 정산 조정, 이중 환불 방지|
|신고/후기 분쟁|증빙 최소수집·안전 조치·상대방 소명|관리자 사유 통지, 이의신청 및 재심, 보복 평가 금지|

접수→접수 확인→자료 보완→양측 의견→관리자 결정→서면 이유/산식 통지→이의신청→별도 재검토→환불·재수업·정산 반영의 기록을 남긴다. 처리 목표시간/기한과 담당 연락처를 운영 전 정한다. 법률상 기한이 우선하며 내부 처리로 소비자의 권리행사를 지연시키지 않는다. 샌드박스 환불은 테스트 원장만 바꾸며 실제 카드 환불이라고 표시하지 않는다.

## 5. 직접 추천·성과 보상 정책 초안

1. **기본 구조**: 가입은 무료이며 추천 링크/코드는 직접 추천자 한 명만 연결하는 제안 구조다. 단계 확장·하위 조직·가입비·자격 유지 구매·모집 수당·수익 보장 없음. 1단계라는 이유만으로 법적 적합성이 보장되지 않으며 모든 현금 지급은 법률·국가·PG·세무 승인 전 비활성이다.
2. **사례 구분**: 사용자→학습자, 강사→강사, 학습자→학습자의 유입 유형을 구분한다. 유입/가입/강사 등록만으로 보상을 발생시키지 않는다. 강사 소개형의 성과 기준(그 강사의 실제 적격 수업 등)과 이해충돌/소비자 보호를 별도로 검토하며 아직 확정하지 않는다.
3. **적격 성과**: 승인된 국가/상품에서 유효한 결제가 확인되고 실제 수업이 검증·완료되며 환불·차지백·분쟁/보류 조건을 통과한 거래만 후보로 삼는다. 테스트 거래는 테스트 후보일 뿐 실제 보상 권리가 아니다. 보상률·기간·상한·귀속 방식·첫 구매 여부는 출시 전 공지·동의를 거쳐 확정한다.
4. **부정 방지**: 자기 추천, 중복 계정·결제, 공모 수업, 허위 완료, 동의 없는 홍보·연락처 수집을 금지한다. 의심 신호만으로 영구 박탈하지 않고 증빙·소명·결정·이의 절차를 제공한다. 확정 보상과 미확정 후보를 구분한다.
5. **환불·조정**: 원거래가 환불/취소되면 미확정 후보를 취소·재계산한다. 일부 환불은 적격 실제 제공분과 공지 산식에 따라 판단한다. 이미 지급된 금액의 환수·상계는 자동 수행하지 않고 법적 근거·계약·고지·소명을 검토한다. 각 변경은 원거래 ID·이유·담당자·시각을 남긴다.
6. **공개·세무**: 보상을 받을 수 있는 추천임을 홍보에서 명확히 밝힌다. 추천인은 사업자/거주지/세무 분류에 필요한 최소 정보만 적법하게 제공한다. 추천 보상은 플랫폼 순이익·강사 보수와 구분하고 세금·증빙·지급명세서를 별도 검토한다. 일반 사용자에게 소득을 보장하는 표현을 쓰지 않는다.
